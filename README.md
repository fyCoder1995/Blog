# 📂 博客分类与标签索引

> 记录本站所有分类（Categories）和标签（Tags），方便写作时快速选用，保持内容结构统一。

---

## 一、分类（Categories）

分类是博客内容的顶层架构，建议控制在 **5~10 个**，每个分类下可包含多篇文章。

| 序号 | 分类名称 | 说明 |
|------|----------|------|
| 1 | 技术笔记 | 编程、框架、工具等学习总结 |
| 2 | 生活随笔 | 日常感悟、游记、书影音 |
| 3 | 项目实战 | 完整项目开发记录与复盘 |
| 4 | 效率工具 | 软件推荐、工作流优化 |
| 5 | 读书笔记 | 书籍摘要、读后感 |

> **使用规范**：一篇文章只能属于一个分类（Hexo 默认）。若需跨类，可用标签补充。

---

## 二、标签（Tags）

标签是文章的细粒度关键词，一篇文章可打多个标签。建议标签数量不限，但尽量复用已有标签。

### 2.1 技术类

- JavaScript / TypeScript
- CSS / HTML / HTML5
- Git / GitHub / Hexo + Github
- 网络
- 计算机安全

### 2.2 生活类

- 文字摘录
- 灵感
- 读书笔记
- 梳理框架

### 2.3 工具类

- Markdown
- 浏览器
- GitHub
- Hexo 

### 2.4 其他

- 资源汇总

> **使用规范**：每篇文章建议标签 **3~5 个**，既不要太少（难以检索），也不要太多（分散重点）。

---

## 三、写作时的快速参考

当你新建一篇博客时，按以下步骤确定分类与标签：

1. **判断文章主体归属** → 选择唯一的分类
2. **提炼 3~5 个核心关键词** → 对照上方标签列表，优先使用已有标签
3. **如有必要，新增标签** → 在本文档末尾追加，并注明首次使用日期
